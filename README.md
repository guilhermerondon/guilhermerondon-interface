# Guilherme Rondon - Portfólio Interface

Bem-vindo ao repositório do **Frontend** do meu ecossistema de projetos. Esta interface foi projetada para transmitir autoridade, disciplina e uma estética *High-End SaaS*. 

## 🚀 Tecnologias e Arquitetura

- **Angular 17+**: Utilizando Standalone Components para uma estrutura limpa e sem módulos.
- **Signals**: Gerenciamento de estado reativo de alta performance.
- **Estética**: *Modern Dark SaaS*, *Glassmorphism*, e tipografia *JetBrains Mono* (destaque para o novo monograma 'GR').
- **Integração de APIs**: Consumo simultâneo de serviços .NET, FastAPI e Go de forma assíncrona.

## 🧠 Filosofia

A consistência molda os resultados. Treinando 6 vezes na semana, levo a mesma disciplina do esporte para a engenharia de software: código limpo, arquitetura sólida e performance sem desculpas.

## 🛠️ Como Executar

```bash
npm install
npm run start
```
Acesse `http://localhost:4200`.

## 🌐 Variáveis de Ambiente
O projeto já está configurado para suportar `environments` para consumo local ou de produção das APIs correspondentes.
